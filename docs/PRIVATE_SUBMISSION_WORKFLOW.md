# Submission workflow

See SUBMISSION.md for the private asynchronous GitHub process. The public
challenge/advisory-packet.json is an unscored sample; an `Assign packet` commit replaces it in
each candidate's own repository with that candidate's scored packet. Annotated
classifications, scoring anchors, golden outputs and independent acceptance remain in separate
restricted storage. A private branch in a public repo, .gitignore or AGENTS.md is not access control.
