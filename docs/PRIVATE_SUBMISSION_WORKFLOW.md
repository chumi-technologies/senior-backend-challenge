# Private asynchronous delivery

See [SUBMISSION.md](SUBMISSION.md) for the self-service workflow: your own private template
copy, ordinary clone, initial handoff, private evidence update and final SHA. A PR is optional.
Only the original contact supplies the second packet; do not guess or search for its contents.

The public starter contains the contract, initial case and proposals. Answers, scoring anchors,
held-out changes, reference implementations and second-packet materials remain in separate
restricted storage. A branch in a public repository, .gitignore or AGENTS.md is not access control.
Do not publish candidate solutions or evaluation records.
