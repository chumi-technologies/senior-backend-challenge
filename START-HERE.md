# Start here: use your own GitHub account

This is the public starter, not a candidate workspace. **No founder-assigned repository is
needed.** Create your own private copy, do the work there, and send its link back.

## 1. Create your copy

Open [the public starter](https://github.com/chumi-technologies/senior-backend-challenge), click
**Use this template → Create a new repository**, choose **your own GitHub account** as owner,
and select **Private**. Keep the default branch only; you do not need a fork or an invitation
from the founder. This keeps your solution out of the public starter and other candidates' view.

## 2. Clone and work

Clone the repository you just created, not the public starter. Replace YOUR-USERNAME and
YOUR-REPOSITORY below with your own values:

```sh
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

GitHub has already initialized its history. **Do not run `git init`, delete `.git`, or reset
history.** Read AGENTS.md before using AI, then follow README.md for setup and the task.
You may work on the default branch; a separate branch or pull request is optional.
Commit the initial decision checkpoint before implementation, then preserve your corrections.

## 3. Send it back

Commit and push your work. In your repository's **Settings → Collaborators**, invite the reviewer
GitHub account named by the person who sent you the challenge. Send that person your repository
link and final commit SHA, plus the initial checkpoint SHA, time spent and any unfinished work
(see docs/SUBMISSION.md). Do not open a PR or issue on the public starter.

Questions or requests for permission go to that same person by email or message. There is no
separate GitHub thread or pre-assigned repository to wait for. Keep your solution private.
